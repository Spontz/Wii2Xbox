# Changelog

## 1.2.5

- The Add controller dialog hides Wii Remotes already listed in the main window. A Windows pairing can still be repaired when its controller is missing from the app.
- A blinking Bluetooth icon shows when the dialog is scanning for devices.
- Scan results appear as selectable rounded rows with a name, Bluetooth address, and device-type icon. Uncategorized devices show the Bluetooth symbol.
- The README screenshot shows three connected Wii Remotes and a Nunchuk.

## 1.2.4

- Forward Xbox game vibration to the corresponding Wii Remote.
- Show the Nunchuk, highlight C and Z, and show the analog stick's direction when moved.
- Improve the pairing dialog on high-DPI displays and add a switch to show other discoverable Bluetooth Classic devices.
