# Update Data

- **Release asset**: Stable version, exact tag, distribution, canonical HTTPS URL, declared byte count, and SHA-256.
- **Staged update**: A verified asset path in an owned per-user cache directory and its expected version and digest.
- **Handoff**: Original process identity, installed executable path, distribution, previous visibility, and readiness and start signals.
- **Result**: Success, unsuccessful update, or Windows restart needed. A result marker suppresses immediate repeat.
