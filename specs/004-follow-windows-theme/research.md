# Decisión de apariencia

La API nativa de WinForms de .NET 10 aplica el modo de aplicaciones en Windows 11 antes de crear controles. Windows 10 conserva la apariencia clásica y el alto contraste usa la paleta del sistema. Los controles ya creados no se vuelven a tematizar automáticamente cuando el usuario cambia el modo. [Documentación de Microsoft](https://learn.microsoft.com/dotnet/api/system.windows.forms.application.setcolormode?view=windowsdesktop-10.0)
