# Language Selection Contract

- The main window exposes one language selector. The three choices are System (Sistema), Español, and English.
- The active interface language remains stable until the app is fully closed using Exit from the notification area. Reopening a hidden window displays the current language and any pending change.
- Manual and background launches resolve the same setting. The portable and installed distributions share the per-account preference.
- Setup selects Spanish for Spanish display languages and English otherwise. The app may subsequently use a different saved preference.
